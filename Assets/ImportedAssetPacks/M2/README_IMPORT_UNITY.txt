Tat ca asset da duoc tach thanh file PNG RGBA rieng, nen trong suot.
Khong kem spritesheet goc.

Import vao Unity:
1. Giai nen M2.zip.
2. Keo ca thu muc M2 vao thu muc Assets cua Unity project.
3. Chon cac PNG can dung -> Texture Type: Sprite (2D and UI).
4. Sprite Mode: Single.
5. Bat Alpha Is Transparency.
6. Voi pixel-art: co the dung Filter Mode = Point (no filter).
   Voi background mem / suong may: Bilinear thuong dep hon.
7. Pixels Per Unit tuy theo scale cua project.

manifest.csv ghi ten file, nhom, kich thuoc va vi tri crop tu anh nguon.
