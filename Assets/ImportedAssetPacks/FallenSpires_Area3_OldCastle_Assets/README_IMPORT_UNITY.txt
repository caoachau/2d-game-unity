Fallen Spires - Area 3 Old Castle individual assets

- Sprite Mode: Single
- Filter Mode: Point (no filter)

- Generate Mip Maps: Off
- Alpha Is Transparency: On

- Terrain / props / architecture: 32
- UI: 100 or Native Size
