MỞ UNITY -> Fallen Spires > Authoring > Open Authoring Library

Thiết kế nhanh:
- Kéo PNG vào Scene: đồ trang trí / background.
- Chọn sprite -> Fallen Spires > Authoring > Create Platform From Selected Sprite: tạo platform có BoxCollider2D.
- Chọn object trong Scene -> Save Selected Scene Object As Prefab: tạo prefab kéo-thả dùng lại.
- Tilemap: Create Ground Tilemap -> Window > 2D > Tile Palette -> kéo ForestTiles/CaveTiles vào palette.
- UI: chọn sprite UI -> Create UI Image From Selected Sprite.

Xem hướng dẫn đầy đủ ở file AUTHORING_GUIDE.md tại thư mục gốc project.
