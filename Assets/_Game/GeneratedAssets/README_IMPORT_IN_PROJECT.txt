FALLEN SPIRES - GENERATED ASSETS IMPORTED INTO PROJECT

Location:
Assets/_Game/GeneratedAssets/FallenSpires_AllAssets_From2Screens/

Main folders:
00_References               - 2 original reference screens
01_MainMenu                 - menu background, logo, buttons, icons, banners, menu character
02_Gameplay                 - master asset sheet + individually separated gameplay assets
03_ExtraCharacterSheets     - additional generated character sheets

Unity import behavior:
- PNG files under this folder are automatically imported as Sprite (2D and UI)
- Filter Mode: Point
- Mip Maps: Off
- Compression: None
- Alpha transparency enabled
- Character PPU: 48
- Gameplay UI/environment/props/effects PPU: 32
- Menu/reference/large images PPU: 100

Important:
- Existing project code, scenes, prefabs, packages and settings were not replaced by this import.
- The generated art is stored in a separate folder so you can delete/replace it safely later.
- Sprite sheets in 03_ExtraCharacterSheets import as a single sprite by default. Change Sprite Mode to Multiple and slice manually if you want frame animation from those sheets.
