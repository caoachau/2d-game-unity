Fallen Spires - All Generated Assets From 2 Screens

Contents:
- 00_References: the two original reference screens used in the chat.
- 01_MainMenu: regenerated assets based on the main menu screen.
- 02_Gameplay: regenerated and separated gameplay assets based on the gameplay screen.
  - MasterSheet: one combined sheet.
  - SeparatedAssets: extracted individual PNG assets for Unity import.
- 03_ExtraCharacterSheets: extra player character sprite sheets generated in the chat.

Recommended Unity import settings:
- Texture Type: Sprite (2D and UI)
- Sprite Mode: Single (or Multiple for sheets you want to slice)
- Filter Mode: Point (no filter)
- Compression: None
- Generate Mip Maps: Off

Notes:
- This package combines the generated assets produced in the conversation for the two screens.
- The separated gameplay assets are easiest to use directly in Unity.
